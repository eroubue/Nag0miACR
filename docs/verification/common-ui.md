# Nag0miUI 框架（Common/）游戏内验证清单

## 范围

ErosUI 移植的 UI 框架（`Common/`）在绝枪战士（GNB）上的整体人工验证：四键控制条、QT 面板、热键面板、设置窗口、生命周期与配置落盘。自动化部分（纯逻辑：槽位换算/拖拽交换/动画收敛/排序合并/图标退化/配置迁移）已由 `Tests/` 覆盖，本文只列必须在真实 Dalamud/游戏环境逐项人工检查的内容。

## 可复现命令

在仓库根目录执行：

```powershell
dotnet build Nag0mi.csproj -c Release
cd Tests; dotnet run -c Release
```

## 游戏内验收（尚未执行）

以下每项给出操作步骤与预期结果；任一不符即视为缺陷。

### 四键控制条

- [ ] 状态切换：左键状态键在 运行⇄暂停 间切换，右键直接关闭 ACR，关闭后左键再开启。预期：图标依次呈 播放(绿)/暂停(黄)/停止(灰)，提示文字同步；宿主运行状态同步变化。
- [ ] 模式循环：左键模式键。预期：按 日随→高难→自定义→日随 循环，按钮文字 N→H→C 同步变化，模式键颜色随模式变换（日随=绿 / 高难=红 / 自定义=黄），切换后 QT 恢复该模式默认值。
- [ ] 自动攻击：左键准星键。预期：宿主自动攻击开关即时切换，按钮开=彩色高亮、关=暗化。
- [ ] 设置贴条：左键齿轮。预期：设置窗贴着控制条向画面内侧展开（右吸附时向左展开，左吸附反之），再点关闭。
- [ ] 拖动与边缘吸附：按住控制条空白处（按钮缝隙，非按钮；底部灰线握把已移除）拖动到屏幕左/右边缘。预期：进入边缘 32×UI缩放 内当帧吸附该侧，拖离解除吸附变自由悬浮；按钮区域按下不触发拖动。
- [ ] 吸附融边形态：吸附到位后贴边侧平直贴边、上下两端呈水滴凹弧融入屏幕边缘（约 0.15s 渐变形变），拖离后渐变恢复胶囊形；自由悬浮时保持完整胶囊形。
- [ ] 位置记忆：吸附右侧、吸附左侧、自由悬浮三种状态分别重载插件（或切职业再切回）。预期：吸附侧与相对高度/位置精确恢复；分辨率或 Dalamud 全局缩放变化后仍贴边且四键完整可见。

### QT 面板

- [ ] 开关视觉：逐一点击若干 QT。预期：启用=彩色图标+绿色描边+底部微光条；关闭=35% 透明度+深灰罩层+红色描边。
- [ ] 同技能角标：观察 无情/爆发(爆)/无情不延后(延)/落地无情(落)、音速破/优先音速破(优)/dot(dot)、弓形/小于3目标时不用弓形(<3)/弓形冲波允许错开无情(错) 等。预期：同技能多 QT 图标相同但右下角角标互不相同；无图标的 QT 退化为问号图标+首字角标。
- [ ] 左键即时开关：战斗中左键 QT。预期：立即写入宿主 QT 状态并影响循环（如关掉「爆发」后不再开无情爆发）。
- [ ] 右键拖拽实时交换：右键按住某 QT 拖过另一格中心。预期：越过即实时交换（让位动画平滑收敛），整个拖拽可连续交换多格；松手后新顺序一次性写入 `GNB.json` 的 `QtOrder`，重载后顺序保持。
- [ ] 锁定禁用拖拽：设置窗 QT面板页勾选「锁定QT排序」。预期：悬浮面板右键拖拽不再换位；设置页显隐勾选不受影响。
- [ ] 布局：QT面板页调整每行格数/间距/缩放滑条。预期：面板即时按网格重排，窗口精确贴合无多余透明边；拖动缝隙移动面板，松手落盘，重载后位置与布局恢复。

### 热键面板

- [ ] 冷却/充能/队列待发：触发带冷却的热键（如 星云、超火流星）。预期：冷却中图标外圈显示圆圈进度条（顶部起顺时针, 随剩余时间消减）并显示居中秒数；多充能技能右下角显示 Charge 贴图充能数（0-3）；队列待发（按下待执行）时按钮呈强调色呼吸罩+加粗描边。
- [ ] 激活金框：释放 亲疏自行/极光/刚玉之心/石之心 且对应 buff 未结束。预期：该热键格覆盖 activeaction 金色贴图框；buff 结束后金框消失。
- [ ] 自定义热键目标角标：目标为「小队成员2-8」时左上角显示 Num 数字贴图；「血量最低的队友/坦克/奶妈/输出」时左上角显示对应职能贴图（062144/062581/062582/062583）。
- [ ] 点击触发：左键各热键。预期：释放对应技能（挑衅/退避指向目标，其余自身），「爆发」键为 QT 切换型（开=高亮）。
- [ ] 拖拽交换：右键按住拖动换位。预期：与 QT 面板一致的实时交换，松手写入 `HotkeyOrder` 并落盘；「锁定热键排序」开启后拖拽禁用。
- [ ] 显隐设置生效：设置窗 Hotkey 页取消勾选某热键。预期：悬浮面板立即少一格，其余按钮顺序不变；重新勾选后按序恢复。
- [ ] 时间轴节点：时间轴编辑器添加 绝枪/热键 节点。预期：下拉框列出全部已注册热键（HotkeyManager 影子面板同一数据源）；时间轴执行到该节点时触发所选热键，等价于点击面板按钮。

- [ ] 进入 ACR：切换到绝枪并启用本 ACR。预期：`OnEnterAcr → Install` 注册控制条/QT面板/设置窗三窗口与热键面板；宿主自带设置窗被接管隐藏，宿主自带 QT 面板被压制不再弹出。
